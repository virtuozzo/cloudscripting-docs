# Independent acceptance fixtures

HTML and page expectations here are hand-authored, never generated by the converter or baseline extractor. The YAML/JSON examples contain literal `${token}` and a final LF. Each mutation changes only the named surface and must produce the asserted issue with a route/location. `code-bytes` checks both visible highlighted text and the textarea copied by the pinned theme.

The inherited broken link exception pins the exact source commit, originating route, and target. Changing any of these stops the exception from matching. It cannot excuse a new broken target or publication.

Artifact tests construct a complete two-prefix artifact and mutate both sealed metadata and payloads. Resealing a defective artifact must not bypass provenance or retained-release checks.

`textarea-cases.json` records literal HTML5 textarea values, independently confirmed with html5lib1.1. An initial raw or entity-decoded LF is consumed exactly once; additional source LFs must remain. CLI fixtures test the Task6 sacrificial `&#10;` contract and detect a missing real leading LF.

`legacy-whitespace-case.json` is a literal diagnostic fixture: TAB indentation and whitespace-only source lines differ from the legacy copied presentation. Exact captured visible/copy text remains required; the fixture permits no normalization or alternate body.
