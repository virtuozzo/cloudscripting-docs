# Welcome to Cloud Scripting Documentation
Cloud Scripting (CS) is a tool for programming the behaviour of Virtuozzo Application Management throughout the application lifecycle: automating frequent tasks, complex CI/CD flows, and clustering configurations.
Use the navigation menu to explore topics or the search box to quickly find information. Select the Cloud Scripting version from the dropdown list.

If you are new to Cloud Scripting, start with the [Overview](/overview/) and the [Quick Start](/quick-start/) guide.

To write your own packages, see the [Creating Manifest](/creating-manifest/) section.

To find ready-to-use examples, check out the [Samples](/samples/) page.
