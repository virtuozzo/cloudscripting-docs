<h1>Welcome to Cloud Scripting Documentation</h1>
<p>Cloud Scripting (CS) is a tool for programming the behaviour of Virtuozzo Application Platform throughout the application lifecycle: automating frequent tasks, complex CI/CD flows, and clustering configurations.</p>
<p>Use the navigation menu to explore topics or the search box to quickly find information. Select the Cloud Scripting version from the dropdown list.</p>

If you are new to Cloud Scripting, start with the <a href="/overview/">Overview</a> and the <a href="/quick-start/">Quick Start</a> guide.

To write your own packages, see the <a href="/creating-manifest/">Creating Manifest</a> section.

To find ready-to-use examples, check out the <a href="/samples/">Samples</a> page.
